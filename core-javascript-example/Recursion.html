What is the primary purpose of a base case in a recursive JavaScript function? To stop the recursion and return a concrete value without making another recursive call. The base case provides a condition where the function can resolve directly, halting the chain of recursive calls. If a recursive function in JavaScript completely lacks a base case, what specific type of error will it throw when executed?
